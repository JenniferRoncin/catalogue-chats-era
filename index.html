Configuration Firebase requise

Ce fichier a besoin des identifiants de ton projet Firebase (gratuit) pour stocker les chats en ligne. Ouvre le fichier HTML dans un éditeur de texte et remplace les 6 valeurs "REMPLACE_MOI" en haut du fichier par la configuration de ton projet Firebase (Paramètres du projet → Vos applications → SDK config).

Une fois fait, recharge cette page.
